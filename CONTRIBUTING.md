# Contributing to CadCraft

Thanks for helping. The most useful contributions right now:

- **Bug reports and feature requests** in the app's own repository, using the issue templates.
- **Real-world test files.** DWG, DXF, IFC, PDF or STEP files you have the right to share that break or stress an app. Strip anything confidential first.
- **Workflow reports.** "In my day job I do X with these commands in this order." These shape what gets built next.

Before a pull request for anything larger than a fix, open an issue so we can agree on the approach. Each repository's `BUILDING.md` says how to run it and its tests.

Contributions are licensed under the Apache License 2.0, the license of every CadCraft repository.

Never submit code, files or assets copied from proprietary CAD software or its SDKs.
